# 📸 Telegram Immich Bot

Многофункциональный Telegram-бот для автоматической загрузки медиафайлов (фото, видео, архивы) из Telegram на ваш личный сервер **Immich**. 

Бот поддерживает **многопользовательский режим**: каждый пользователь привязывает свой собственный API-ключ Immich через команду `/setup`, и файлы загружаются строго в его личный аккаунт без использования глобальных ключей.

## ✨ Основные возможности

- 🔐 **Многопользовательская архитектура**: Нет глобального API-ключа. Каждый пользователь настраивает бота под себя.
- 📁 **Поддержка архивов**: Автоматическая распаковка `.zip`, `.rar`, `.7z`, `.tar`, `.gz` и загрузка содержимого.
- 🚀 **Загрузка больших файлов**: Использование библиотеки `Telethon` для скачивания файлов размером более 20 МБ (ограничение стандартного Bot API).
- 🏷️ **Умные теги**: Распознавание `#album <имя>` и `#fotografo <имя>` в подписи к файлу. Бот автоматически создаст альбомы и добавит фотографа в описание.
- 🧹 **Очистка описания**: Служебные теги автоматически удаляются из текста, и в Immich сохраняется только чистый пользовательский текст.
- 👀 **Watch Folder (Автоимпорт)**: Мониторинг папки `/import`. Любые файлы, помещенные в эту папку, будут автоматически загружены в Immich.
- 🔒 **Active-Passive High Availability**: Встроенный механизм блокировок (lock file) позволяет запускать несколько экземпляров бота без риска дублирования загрузок.

---

## ⚙️ Требования

1. Работающий сервер **Immich**.
2. Токен Telegram-бота (получить у [@BotFather](https://t.me/BotFather)).
3. *(Рекомендуется)* `API_ID` и `API_HASH` от Telegram (получить на [my.telegram.org](https://my.telegram.org)) для загрузки файлов > 20 МБ.
4. Docker и Docker Compose (рекомендуемый способ установки).

## 🚀 Установка и запуск (Docker)

Склонируйте репозиторий
```
git clone https://github.com/apnagaev/telegram-immich-bot.git
```
Запустите build
```
cd telegram-immich-bot
docker build -t immichtelebot .
```
Исправьте telethon_session.sh, изменив API_ID = 1111111 и API_HASH = "11111111111111111111111"  на Ваши ID и HASH из https://my.telegram.org/
запустите telethon_session.sh
```
bash ./telethon_session.sh
```

Пивяжите telegram_session.session к Вашему docker-контейнеру

## 🔑 Настройка прав API-ключа в Immich

При создании API-ключа в Immich **НЕ используйте разрешение "All"**

Вручную отметьте **эти 10 разрешений**:

| Разрешение | Зачем нужно боту |
| :--- | :--- |
| `user.read` | Получение email и имени пользователя для привязки аккаунта. |
| `asset` | Базовый доступ к ассетам. |
| `asset.read` | Проверка метаданных для выявления дубликатов. |
| `asset.download` | Скачивание оригинала файла для проверки контрольной суммы. |
| `asset.upload` | Загрузка новых фото и видео. |
| `asset.update` | Добавление описания (caption) и имени фотографа к файлу. |
| `album` | Базовый доступ к альбомам. |
| `album.read` | Поиск существующих альбомов по имени. |
| `album.create` | Создание нового альбома (например, "Telegram Upload"), если он не найден. |
| `albumAsset.create` | Добавление загруженного файла в указанный альбом. |

> 💡 **Как создать ключ:** Immich → Профиль → Account Settings → API Keys → New API Key → вручную проставить 10 галочек выше → Generate → скопировать ключ.

## 📱 Использование бота

### 1. Первоначальная настройка (`/setup`)
1. Отправьте боту команду `/setup`. Бот покажет список необходимых прав и инструкцию.
2. Создайте API-ключ в Immich с указанными выше 10 правами.
3. Отправьте боту команду: `/setup ВАШ_API_КЛЮЧ`
4. Бот проверит ключ, убедится в наличии всех прав, сохранит привязку и подтвердит успешную настройку.

### 2. Проверка статуса (`/status`)
Команда `/status` покажет:
- Привязанный Email и Telegram ID.
- Имя пользователя из Immich.
- Замаскированный API-ключ.
- Детальный отчёт о проверке всех 10 разрешений (✅ или ❌).

### 3. Отправка файлов
Просто отправьте боту фото, видео, документ или архив. Вы можете добавить подпись (caption) с тегами:

> Отличные кадры с отпуска! 🌴
> #album Отпуск 2024
> #fotografo Иван Иванов

**Что сделает бот:**
1. Загрузит файл в ваш аккаунт Immich.
2. Создаст (или найдёт) альбом "Отпуск 2024" и добавит туда файл.
3. В описание файла в Immich запишет: `Отличные кадры с отпуска! 🌴\n\nFotografo: Иван Иванов` (служебные теги будут аккуратно удалены из текста).

## 📂 Watch Folder (Автоимпорт)

Бот постоянно (каждые 30 секунд) мониторит папку, указанную в переменной `IMPORT_DIR` (по умолчанию `/import`).

- Если вы поместите туда фото, видео или архив (например, через сетевую папку SMB/NFS), бот автоматически обработает их так же, как если бы вы отправили их в чат.
- Файлы будут загружены в аккаунт **первого пользователя**, указанного в файле `data/user_mapping.json`.
- После успешной загрузки исходные файлы из папки `/import` **удаляются**.
- Если ни один пользователь не выполнил `/setup`, импорт будет пропущен с предупреждением в логах.

## ⚙️ Переменные окружения

| Переменная | Обязательная | Описание |
| :--- | :---: | :--- |
| `TELEGRAM_TOKEN` | ✅ | Токен вашего бота от [@BotFather](https://t.me/BotFather). |
| `IMMICH_URL` | ❌ | URL вашего сервера Immich (по умолчанию: `http://immich:2283`). |
| `TELEGRAM_API_ID` | ❌ | API ID для Telethon (нужен для загрузки файлов > 20 МБ). |
| `TELEGRAM_API_HASH` | ❌ | API Hash для Telethon. |
| `IMPORT_DIR` | ❌ | Путь к папке автоимпорта внутри контейнера (по умолчанию: `/import`). |
| `LOCK_FILE_PATH` | ❌ | Путь к файлу блокировки для Active-Passive HA (по умолчанию: `/shared_storage/bot.lock`). |
| `MAX_CONCURRENT_TELETHON_DOWNLOADS` | ❌ | ↓ до 2 при слабом канале. |
| `MAX_CONCURRENT_EXTRACTS` | ❌ | ↓ до 1 при медленном диске. |
| `MAX_CONCURRENT_UPLOADS` | ❌ | 6 |
| `MAX_CONCURRENT_UPLOADS_PER_JOB` | ❌ | 3 |
| `MAX_CONCURRENT_JOBS_PER_USER` | ❌ | 2. |
| `IO_MAX_WORKERS` | ❌ | 16 |
| `CPU_MAX_WORKERS` | ❌ | 4 |
| `TEMP_DIR` | ❌ | /tmp/bot_downloads_${HOSTNAME} |

## 🔧 Устранение неполадок

### ❌ Ошибка "Неверный API ключ или ошибка подключения"
- Проверьте, правильно ли указан `IMMICH_URL` (должен быть доступен из контейнера бота, например, `http://immich_server:2283` внутри Docker-сети).
- Убедитесь, что ключ скопирован полностью, без лишних пробелов в начале или конце.

### ❌ Ошибка 403 при проверке прав
- Вы забыли отметить одно из 10 обязательных разрешений при создании ключа в Immich.
- **Решение:** удалите старый ключ, создайте новый и внимательно проставьте ровно 10 галочек из таблицы выше. **Не используйте "All"**.

### ❌ Большие файлы (> 20 МБ) не загружаются
- Убедитесь, что переменные `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` заданы корректно.
- Проверьте, что файл сессии `telegram_session.session` успешно создан и сохранён в проброшенном томе Docker.
- Если сессия не создана — создайте её локально (через `telethon`) и пробросьте в контейнер.

### ❌ Файлы из Watch Folder не загружаются
- Проверьте права доступа к папке `/import` внутри контейнера (должны быть читаемы).
- Убедитесь, что в `data/user_mapping.json` есть хотя бы один настроенный пользователь (через команду `/setup`).
- Проверьте логи контейнера: если пользователей нет, бот пишет предупреждение и пропускает импорт.

### ⚠️ Проверка прав показывает "Не проверено" для некоторых пунктов
- Это нормально для нового аккаунта Immich, в котором ещё нет ассетов или альбомов.
- **Решение:** загрузите хотя бы одно фото и создайте хотя бы один альбом через веб-интерфейс Immich, затем повторите `/status`.
